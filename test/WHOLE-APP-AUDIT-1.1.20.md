日期：2026-10-27。安装目录：`Z:\MiniMax-H3-Studio\App`。

## 已确认并修复的问题

| 问题 | 触发方式与影响 | 修复 |
| --- | --- | --- |
| 视频接口接受非视频文件 | `video.delete/rename` 传入 output 下的 WAV、PNG，也能操作，可能误删其他工具结果 | 限定视频扩展名和普通文件；图片工具的“打开位置”单独保留支持 |
| 输出目录边界仅做字符串判断 | output 内的目录联接指向外部，视频操作可落到外部文件 | 校验真实路径，拒绝符号链接文件，扫描跳过目录联接；同时允许合法的 `..clip.mp4` 名称 |
| 清空模式拼错会删除文件 | `video.clear` 的 mode 为 `record` 等未知值时按永久删除处理 | 仅接受 `delete`、`records`，未知值在任何文件操作前拒绝 |
| 只清记录后刷新又出现 | 删除元数据后扫描器重新把保留的视频列入历史 | 持久化隐藏标记，刷新仍隐藏；后续明确删除文件时也会处理隐藏的视频 |
| 设置保存失败仍返回成功 | 磁盘满或写入被拒绝时，原先在延迟任务中报错，调用方先收到成功 | 写入成功后才返回成功，失败恢复内存状态；界面显示保存错误，语音草稿也处理 `ok:false` |
| 批量 ZIP 导出失败或误报成功 | 从 PowerShell 7 启动时模块路径可能令 Windows PowerShell 找不到 Compress-Archive；旧 ZIP 存在时还可能误报成功 | 使用系统模块路径与终止错误，在临时 ZIP 成功后替换目标，失败保留已有导出 |
| 外部生成的语音不会自动出现在界面 | 在语音页面打开时，通过 CLI 生成结束，历史仍是旧列表 | 收到结束事件后重新读取语音状态和历史 |
| 删除试听中的语音仍继续播放 | 浏览器缓冲的音频可能在文件删除后继续播放 | 删除当前音频前停止播放器并更新播放状态 |
| 简写画幅通过校验却生成失败 | CLI/API 提交 `aspectRatio:"1:1"` 时，底层 ResolutionSelector 要求完整名称 | 对 `1:1`、`16:9`、`9:16` 及带名称写法统一转换为底层有效选项 |
